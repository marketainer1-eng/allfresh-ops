# 크로스채널 통합 규칙 (올프레쉬 멀티채널)

> **언제 읽나**: **2개 이상 판매채널**(자사몰·스마트스토어·카카오톡스토어 등) 데이터를 함께 합칠 때.
> **적용 순서**: 채널별로 (채널 스킬 + 과일선물세트 잣대) 각각 분석 → 이 문서로 통합.
> **목표**: 단순 합산이 아니라 **이중집계 없는 정확한 통합 인사이트.**

---

## 1. 소스 3분류 (혼동 금지 — 통합의 전부)
합치기 전 모든 데이터를 분류한다.
1. **판매처(매출 발생지)**: 자사몰(카페24)·스마트스토어·카카오톡스토어 → **매출(revenue)의 단일 출처.**
2. **광고/유입 채널(비용·기여)**: 네이버 검색/쇼핑광고·GFA, 카카오 광고, 구글/유튜브 등 → **비용 + 기여(추정).** 매출 출처가 아님.
3. **오가닉/직접**: 자연검색·직접유입·재방문.

> **★ 철칙: 매출은 '판매처'에서만 센다. '광고/유입 채널'은 비용과 기여(추정)로만 반영한다.** 광고 채널을 판매처처럼 매출에 더하면 이중·삼중 집계가 발생한다. (예: 자사몰 애널리틱스의 "Naver 기여매출"을 스마트스토어 매출과 더하지 않는다.)

### 1-1. 광고 → 판매처 라우팅
광고는 **각 캠페인이 어느 판매처로 보내도록 셋팅됐는가(랜딩 목적지)** 로 연결한다. 그 목적지 매출과 묶어 "광고가 그 판매처를 얼마나 활성화했나"를 본다. 한 캠페인이 여러 목적지로 가면 캠페인 단위로 배분, 불명이면 "미배분"으로 따로 둔다. **통합은 판매처 중심**: "각 판매처 + 그 판매처로 유입시키는 광고" 한 덩어리로 본 뒤 판매처들을 합산.

## 2. 표준화 (합치기 전 필수 선행)
지표 정의가 채널마다 다르므로 한 기준으로 맞춘다.
- **매출 정의 통일**: 총주문금액 / 결제금액 / **순매출(취소·환불 차감)** 중 하나로 — 기본 **순매출(확정 기준)** 권장. 각 채널이 부르는 "매출"이 무엇인지 먼저 확인.
  - 올프레쉬 주의: 자사몰 월별매출에는 **네이버포인트·적립금·환불**이 따로 잡힌다 → 순매출 = 결제합계 − 환불합계 기준으로 통일하고 포인트/적립은 별도 추적.
- **기간·타임존**: 결제일 기준·KST·동일 기간 윈도우 정렬. **시즌 플래그(성수기/비수기)를 함께 태깅**(§5 참조).
- **세금·배송비·통화**: VAT·배송비 포함 여부 통일.
- **SKU 매핑 키**: 채널마다 상품코드·상품명이 다르다 → **통합 SKU 매핑 테이블**(상품명/내부코드로 매칭) 작성. 없으면 SKU 단위 통합 보류하고 **채널 단위까지만** 통합.

## 3. 어트리뷰션 / 이중집계 처리 (가장 중요)
- **플랫폼 보고 전환은 서로 겹친다.** 네이버·카카오·구글이 각자 어트리뷰션 창으로 같은 전환을 중복 카운트한다. → **플랫폼 ROAS 단순 합 ≠ 실제 효율.**
- **판매처 매출 = 매출의 단일 진실(SSOT).** 광고 플랫폼·애널리틱스의 보고 전환·기여매출은 **방향성 참고(추정)** 로만.
- **블렌디드(MER)를 1순위 효율 지표로.** `블렌디드 ROAS(MER) = 총 순매출(판매처 합) ÷ 총 광고비(플랫폼 합)`.
- **채널별 효율**은 플랫폼 보고치를 **상대 비교·추세**로만. "정확한 채널 ROAS"로 단정 금지.

### 3-1. 측정 렌즈 3종은 서로 다르다 (지표 불일치는 정상)
같은 광고·기간이라도 ①광고 플랫폼 보고(자기 픽셀·자기 창 — 가장 부풀고 중복) ②판매처 분석/애널리틱스(GA4·카페24 애널리틱스 등, 보통 라스트클릭) ③판매처 백엔드 실주문(정산·확정)의 숫자는 **절대 일치하지 않는다.** 오류가 아니라 측정 대상이 다른 것이다.

### 3-2. 지표별 진실의 출처 (SSOT by metric — 고정)
- **매출** = **판매처 백엔드 실주문**(정산·확정). 광고 플랫폼·애널리틱스 매출 아님.
- **채널/소스별 매출 배분** = **판매처 분석(애널리틱스)**, 단 방향성 참고로만.
- **비용·노출·클릭·CPC** = **광고 플랫폼**(이건 플랫폼이 진실).
- **효율** = **블렌디드 ROAS(MER)**. 플랫폼 보고 ROAS는 추세·상대비교용.
→ 서로 다른 출처 숫자를 한 줄에 섞어 "맞다/틀리다" 비교하지 말고, 각 지표를 위 출처에서만 가져온다.

## 4. 통합 KPI 세트 — 기여이익 중심 (올프레쉬는 원가·수수료 보유)
매출 외형이 아니라 **채널별 기여이익**이 핵심이다. 수수료·포인트 구조가 채널마다 다르므로 **외형 매출 1등 채널이 이익 1등이 아닐 수 있다.**

**채널별 기여이익 = 순매출 − 원가(COGS) − 채널 판매·결제 수수료 − 광고비 − 할인·쿠폰·적립/포인트 부담**

| 통합 KPI | 정의 | 비고 |
|---|---|---|
| 통합 순매출 | 판매처 순매출 합(중복 제거) | SSOT=판매처 실주문 |
| 채널별 매출 믹스 | 채널 순매출 ÷ 통합 순매출 | 채널 의존도 |
| **채널별 기여이익 / 이익률** | 위 공식 | **외형 매출과 순위 비교 필수** |
| 총 광고비 / 블렌디드 ROAS(MER) | 판매처 실매출 ÷ 총 광고비 | 효율 진실 |
| 채널별 환불률 | 환불 ÷ 매출 | 신선식품 리스크 |
| 신규/재구매 비중·CAC | 가능 시 | 목적: 신규·리텐션 |

### 4-1. 채널 비대칭 점검 (올프레쉬 특화)
같은 선물세트라도 채널 경제가 다르다 — 분석 시 명시한다.
- **스마트스토어**: 네이버 판매수수료 + **네이버포인트 적립 부담**(실데이터상 자사몰에서도 네이버포인트 큼). 검색 유입 강함.
- **자사몰(카페24)**: PG 결제수수료 위주(상대적으로 수수료 낮음) + 자체 마케팅/획득 비용. 브랜드 직접 관계.
- **카카오톡스토어**: 카카오 수수료·정산 구조(채널 스킬/사용자 확인). 메신저·선물하기 맥락.
→ **수수료율·원가를 적용해 채널별 기여이익을 산출**하고, "어디서 팔리나"와 "어디서 남나"를 분리 제시한다.

## 5. 시즌 동기화 (올프레쉬 통합의 필수 가드)
모든 채널이 명절에 동시 폭증한다. 통합 시계열을 **직전기간 비교로 그리면 "전 채널 동반 급락"이라는 무의미한 노이즈**만 나온다.
- 통합 비교는 **전년 동기(YoY)** 또는 **성수기/비수기 분리**를 기본으로.
- 각 데이터에 시즌 플래그를 태깅하고, 통합 표/차트에 시즌 구간을 표시한다.
- 채널 간 시즌 반응 **차이**는 인사이트다(예: 자사몰은 설에 더 쏠리고 카카오는 평시 선물 비중이 높다 등 — 가설로 두고 검증).

## 6. 채널 카니발라이제이션 점검 (목적: 진단)
멀티채널만이 줄 수 있는 진단. 동일 고객/상품이 채널 간 잠식하는지 본다.
- **같은 SKU의 채널별 가격·마진·환불률 차이**: 한 채널이 더 싸서 다른 채널 매출을 잠식하는지. 함부로 평균내지 말고 차이 자체를 분석.
- **자사몰 "Naver 기여" vs 스마트스토어 매출 중복 의심**: 고객이 자사몰을 보고 스마트스토어에서 결제(또는 반대)하는 경로. 어트리뷰션을 매출에 더하지 말고, 중복 가능 구간을 "이중집계 의심"으로 리스크 보고.
- 채널 충돌이 의심되면 **가격·노출 정책 일원화** 또는 채널별 차별화(자사몰 단독 구성/혜택)를 액션으로.

## 7. 통합 분석 순서 (고정)
1. 채널별 (채널 스킬 + 잣대) 분석 결과 수집 — 각자의 정합성·한계 먼저.
2. §2 표준화(매출 정의·기간·시즌 플래그·SKU 정렬).
3. §3 적용: 매출=판매처 합(중복 제거), 광고=비용·기여만.
4. §4 통합 KPI 산출 → **채널별 기여이익** + 블렌디드 효율.
5. §5 시즌 동기화, §6 카니발라이제이션 점검.
6. 마스터 §5 목적 가중치 적용(진단·신규·리텐션) + 필수 리스크 보고.
7. 산출: 통합 Executive Summary → 목적 기준 우선순위 인사이트(채널 예산·노출 배분 포함) → 필수 리스크(채널 과의존·적자 채널·이중집계 의심) → 데이터 한계·추가수집.

## 8. 충돌 해소 위계 (채널 간)
- **매출 충돌**: 판매처 정산·확정 > 광고/애널리틱스 보고치.
- **효율 충돌**: 블렌디드(MER) > 플랫폼 보고 ROAS.
- **채널 간 SKU 차이**: 수수료·고객층·가격 차이로 해석, 평균내지 않음.

## 9. 금지 / 주의
- 플랫폼 보고 ROAS 합산·실측 단정 금지.
- 광고 기여매출을 판매처 매출에 더해 총매출 부풀리기 금지.
- 서로 다른 매출 정의(총주문 vs 순매출) 혼합 비교 금지.
- **시즌 무시한 직전기간 단순 비교 금지**(올프레쉬 최대 함정).
- 원가/수수료 없이 채널 수익성 단정 금지 — 있으면 기여이익까지, 없으면 외형 매출만 + 한계 명시.
- 한 채널만 있는데 "전체 채널 효율"로 일반화 금지 — 보유 범위 명시.
