# 올프레쉬 통합 성과분석 — 런 준비 체크리스트

> 이 문서대로 데이터를 모아 클로드 프로젝트에 올리면, 통합 분석 → 보고서까지 **한 번에** 실행됩니다.
> 매 분석 주기(월간/명절 후 등)마다 재사용하세요.

## 0. 1회 설치 (최초 1번)
- [ ] 프로젝트 스킬에 **3종 모두** 추가되어 있는지 확인:
  - `allfresh-integrated-analysis` (마스터 — 신규)
  - `cafe24-analysis` (자사몰)
  - `smartstore-analysis` (스마트스토어)
- [ ] 카카오톡스토어 전용 스킬은 아직 없음 → 마스터의 "임시 규칙(판매처로 취급)"으로 동작. 정식 스킬은 카카오 export 스키마 확정 후 추가.

## 1. 분석 스코프 먼저 정하기 (가장 중요)
- [ ] **기간**: 예) 2026-01-01 ~ 2026-02-28
- [ ] **시즌 플래그**: 성수기(설·추석 포함) / 비수기 / 혼합 — *이게 비교 해석을 좌우합니다.*
- [ ] **비교 기준**: **전년 동기(YoY) 권장.** 직전기간 비교는 시즌 왜곡 주의.
- [ ] **목적 가중치(기본 고정)**: 진단 · 신규획득 · 리텐션
- [ ] 모든 채널의 **기간을 동일하게** 맞춰서 export

## 2. 채널별 수집 파일

### 2-A. 자사몰 (카페24) — ✅ 현재 프로젝트에 있음
이미 보유: 월별 매출내역 · 구매 분석 · 상품별 매출 · 이탈/포기 상품 · 구매단계(퍼널) · 채널별 기여 · 구매전환 경로 · 연령/재구매 등.
- [ ] 분석 기간에 맞는 최신본인지만 확인. (지금 있는 건 ~2026-06 일부 포함)

### 2-B. 스마트스토어 — ⬜ 필요 (네이버 커머스솔루션/스토어 통계에서 export)
- [ ] **구매확정내역** (주문 라인 단위 — 순매출·수익성의 기준)
- [ ] **판매성과** (날짜×요일×시간대 시계열)
- [ ] **상품성과** (SKU별 — topSku용)
- [ ] **재구매통계**
- [ ] **마케팅채널 / 검색채널 리포트** (전환 키워드 — attribution·신규획득용)
- [ ] **광고비 소진내역** (있으면 — ROAS/MER용)
- [ ] (있으면) 배송통계·고객프로파일

### 2-C. 카카오톡스토어 — ⬜ 필요
- [ ] **정산내역 / 주문내역** (순매출·수수료 기준)
- [ ] **상품별 판매 내역** (SKU)
- [ ] (있으면) 채널/유입·환불 내역
- ※ 카카오 export 컬럼명이 불명확하면, 파일 1개 올려주시면 스키마부터 같이 확정합니다.

## 3. 비용 입력 (기여이익 산출 — ★ 보유 중이라 하셨으니 꼭)
외형 매출이 아니라 **채널별 기여이익**으로 비교하려면 필요합니다. 표/메모 어떤 형태든 OK.
- [ ] **채널별 판매·결제 수수료율**: 자사몰(PG) ___% / 스마트스토어 ___% / 카카오 ___%
- [ ] **원가**: 주력 SKU 원가 또는 평균 원가율 ___%
- [ ] **광고비**: 채널/플랫폼별 기간 광고비 (있으면 — MER 산출)
- [ ] **할인·적립/포인트 부담**: 네이버포인트·적립금 등 (자사몰 월별매출에 이미 잡힘)

## 4. 통합 SKU 매핑 (선택 — 있으면 상품단위 통합)
- [ ] 같은 상품의 채널별 코드/상품명 매칭표 (예: 자사몰 868 = 스마트스토어 △△ = 카카오 ○○)
- [ ] 없으면 → **채널 단위까지만** 통합(그래도 분석 가능).

## 5. 실행 (데이터 다 모인 뒤, 클로드에 한 줄)
예시 요청:
> "올프레쉬 [기간] 통합 성과분석 돌려줘. 자사몰은 프로젝트 데이터, 스마트스토어·카카오는 방금 올린 파일. 시즌=성수기, 비교=YoY, 수수료율/원가는 첨부 메모 참고. 보고서는 xlsx로."

그러면 클로드가 자동으로:
1. 채널 식별 → 정합성·시즌 플래그 확인
2. 채널별 계산(코드 실행: 순매출·기여이익·퍼널·세그먼트)
3. 과일선물세트 잣대 + 크로스채널 통합(매출=판매처, 어트리뷰션=방향참고, MER, 채널충돌)
4. 목적 가중치(진단·신규·리텐션)로 인사이트 정렬 + 필수 리스크
5. 산출: Executive Summary → 통합 KPI 표(매출·기여이익 순위 분리) → 인사이트 카드 → 리스크 → 데이터 한계, (요청 시) docx/xlsx 보고서

## 6. 최소 실행 조건
- 자사몰만으로도 단일채널 진단은 지금 즉시 가능.
- **통합(멀티채널) 인사이트**는 최소 2개 채널 데이터 + (정확한 수익성엔) 수수료율·원가 필요.
- 카카오는 export 1개로 스키마 확정 후 합류.
